# RETO1_Ethan

## Ejecución del proyecto

Para ejecutar la aplicación es necesario tener Python 3 instalado.

1- Descargar o clonar el repositorio.

2- Abrir una terminal en la carpeta raíz del proyecto, donde se encuentra main.py.

Ejecutar el siguiente comando:

    python main.py

La aplicación mostrará un menú desde el que se podrán gestionar los libros, los socios, los préstamos y las devoluciones. Los cambios se pueden guardar mediante la opción 8 del menú.
